# VladiMir TV

Простой IPTV-плеер для Android / Fire TV: ввод прямой ссылки на поток или M3U-плейлист, выбор канала и воспроизведение через Media3.

Для сборки: GitHub Actions → Build VladiMir-TV APK → Run workflow. Скачайте артефакт `VladiMir-TV-debug` после успешной сборки.

Ограничения: плейлисты с авторизацией, специфическими заголовками, DRM, Xtream Codes, EPG не поддерживаются. Используйте только потоки, на просмотр которых у вас есть право. На Fire TV ввод URL с пульта неудобен; для длинных ссылок можно использовать приложение-пульт с клавиатурой.
